CSS LENGTH UNITS

Web 前端的长度单位

写 CSS 时，宽度、高度、内外边距、字号……几乎所有尺寸值后面都要跟一个单位。下面把网页开发中常用的长度单位分成「绝对单位」和「相对单位」两类，每个单位都配了一条真实长度的色条，可以直观对比。

一、绝对单位 大小固定不变，浏览器里最终都会换算成 px

px 像素 pixel

屏幕上最基本的显示单位，网页开发中用得最多。它是一个固定值，不会随窗口或字号改变。

width: 120px 固定 120 像素

in 英寸 inch

英制长度单位，1 英寸 = 2.54 厘米。屏幕按 96dpi 换算，所以 1in 就是 96px。

width: 1in = 96px

cm 厘米 centimeter

公制长度单位，日常最熟悉的尺寸。按 96dpi 换算，1cm ≈ 37.8px。

width: 2cm ≈ 75.6px

mm 毫米 millimeter

比厘米更精细，10mm = 1cm，常用于打印稿的精确排版。

width: 20mm ≈ 75.6px

pt 磅 point

印刷行业的传统单位，1pt = 1/72 英寸 ≈ 1.33px，字体大小常常用它表示。

width: 72pt = 96px

pc 派卡 pica

排版单位，1 派卡 = 12 磅。在网页里较少使用，了解即可。

width: 6pc = 96px

注意看色条：1in、72pt、6pc 三条色条长度完全一样（都是 96px）—— 绝对单位只是写法不同，在屏幕上最终都会换算成像素。

二、相对单位 跟着参照物变化，是响应式布局的主力

% 百分比 percentage

相对父元素：宽度相对父元素的宽度，高度相对父元素的高度。做流式布局最常用。

width: 62% 占虚线框宽度的 62%

em 相对当前字号

相对当前元素自己的 font-size：1em = 自己的字号。嵌套时会一层层叠加放大。

width: 8em = 8 × 16px = 128px

rem 相对根字号

相对根元素 <html> 的 font-size，不管嵌套多少层都取同一个值，适合整页缩放。

width: 8rem = 8 × 16px = 128px

ex x 高度

相对当前字体中小写字母 x 的高度，大约是字号的一半，排版时用来对齐字母。

width: 16ex ≈ 16 个 x 的高度

ch 数字 0 宽度

相对当前字体中数字「0」的宽度，常用来限制一行最多能排多少个字符。

width: 16ch ≈ 16 个数字 0

vh 视口高度

视口（浏览器可视区域）高度的 1%，100vh 就是一整个窗口的高度。

height: 6vh 窗口高度的 6%

vw 视口宽度

视口宽度的 1%，100vw 就是一整个窗口的宽度，常用于满屏区块。

width: 10vw 窗口宽度的 10%

vmin 较小视口单位

取 vw 和 vh 中较小的那一个，适合做「在任何屏幕上都不会溢出」的尺寸。

width: 22vmin 宽高中取较小值

vmax 较大视口单位

取 vw 和 vh 中较大的那一个，横竖屏切换时始终贴近较长的那一边。

width: 14vmax 宽高中取较大值

拖动浏览器窗口试试：% 始终相对虚线框变化；vw、vmin、vmax 的色条会跟着窗口变长变短；把窗口拉矮，vh 的竖条也会跟着变。

三、em 与 rem 的区别 嵌套时 em 层层叠加，rem 永远不变

em：跟着自己的字号走

下面三层都写 font-size: 1.5em：24px → 36px → 54px，色条 width: 4em 也跟着越变越长。

第 1 层：1.5em = 24px，4em = 96px

第 2 层：1.5em = 36px，4em = 144px

第 3 层：1.5em = 54px，4em = 216px

rem：永远只看根字号

同样三层都写 font-size: 1.5rem：永远是 16px × 1.5 = 24px，色条 width: 4rem 三层一样长。

第 1 层：1.5rem = 24px，4rem = 64px

第 2 层：1.5rem = 24px，4rem = 64px

第 3 层：1.5rem = 24px，4rem = 64px

四、常用换算与怎么选

写法 换算关系
1in = 96px = 2.54cm = 25.4mm
1cm ≈ 37.8px
1mm ≈ 3.78px
1pt = 1/72 in ≈ 1.33px（印刷“磅”）
1pc = 12pt = 16px（派卡）
1em = 当前元素的 font-size（默认 16px），嵌套时叠加
1rem = 根元素 html 的 font-size（默认 16px）
100vh / 100vw = 整个视口的高度 / 宽度
vmin / vmax vw 与 vh 中较小 / 较大的一个
  • 整页等比缩放 → rem
  • 相对自身字号（图标、行高）→ em
  • 撑满父容器 → %
  • 满屏区块、通栏 → vh / vw
  • 移动端安全尺寸 → vmin
  • 打印精确尺寸 → cm / mm / pt
