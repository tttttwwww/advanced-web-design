为什么这三个接口能跨域

  • 页面是从本地 file:// 或 Live Server 打开的，域名和接口的域名完全不同，这是标准的跨域请求。
  • 浏览器肯放行的原因是响应头里带了 Access-Control-Allow-Origin：JSONPlaceholder 会把你页面的 Origin 原样回写（用 file:// 直接打开时回写的是 null），Dog CEO 则直接给 *，表示谁都给。
  • JSONPlaceholder（用户 / 文章）和 Dog CEO（随机狗图）都是教学用的公开接口，不注册、不带密钥，直接 fetch 即可。
  • 请求失败时页面会显示原因：断网、超时，或者那个接口没有返回跨域响应头。
fetch('https://jsonplaceholder.typicode.com/users')
  .then(function (res) { return res.json(); })
  .then(function (data) { console.log(data); });
