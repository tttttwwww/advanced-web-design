# 汽水音乐 · Soda Music

一个仿「汽水音乐」的网页播放器（纯前端静态站点，**双击 `index.html` 就能跑**，不用装环境、不用联网）。
作者：**涂玮轩**

## 功能

### 推荐页（全屏竖滑）

| 模块 | 说明 |
| --- | --- |
| 全屏竖滑切歌 | 鼠标滚轮 / ↑↓ / 触摸上下滑，整页吸附切换，滑到哪首播哪首 |
| 大封面 | 5 种封面花纹（sun / blob / grid / wave / ring）+ 高光扫过 + **鼠标 3D 倾斜** |
| 动态配色 | 背景光晕、进度条、频谱颜色跟着当前歌曲的主色变化 |
| 歌词滚动 | 按时间戳逐行高亮、自动居中，**点歌词可以跳到那一句** |
| 音频频谱 | 28 根实时频谱柱，跟着声音跳动 |
| 右侧操作栏 | 喜欢、评论、分享、播放列表 |

### 精选页 / 我的页

| 模块 | 说明 |
| --- | --- |
| 精选歌单 | 卡片网格，显示封面 / 标签 / 时长，点卡片直接播放并跳回播放页 |
| 我喜欢的音乐 | 收藏过的歌会留在这里，空的时候有占位提示 |
| 评论面板 | 从底部滑出，展示该曲评论，可以发一条（只存在本地，刷新即消失） |
| 搜索 | 输入关键词实时过滤播放列表，回车播放第一条结果 |

### 播放与记忆

| 模块 | 说明 |
| --- | --- |
| 三种播放模式 | 列表循环 / 单曲循环 / 随机播放（左下角两个按钮切换） |
| 静音 | 音量按钮一键静音，图标同步变化 |
| 自动记忆 | 喜欢的歌、音量、播放模式、上次听到第几首，都会存在浏览器里，下次打开接着听 |
| 系统媒体控制 | 支持键盘媒体键 / 锁屏控制（MediaSession API） |
| 快捷键 | `空格` 播放暂停 · `↑↓` 切歌 · `←→` 快退快进 5 秒 · `L` 喜欢 · `Esc` 关面板 |

## 声音从哪来？

没有 mp3 也不会哑巴 —— 项目用 **Web Audio API 现场合成**音乐：
和弦铺底（pad） + 贝斯 + 底鼓/踩镲 + 琶音，再加上**程序生成的混响**。

每首歌有自己的 BPM、调式、和弦进行和音色（三角波 / 方波 / 锯齿波），
而且**每个 4 小节循环一次段落变化**：主歌 → 推进 → 副歌（升八度、加鼓） → 收尾，
所以听起来是有起伏的，不是一个 loop 从头混到尾。

## 换成自己的歌

1. 把 mp3 放进 `audio/` 文件夹，例如 `audio/我的歌.mp3`；
2. 打开 `js/data.js`，给对应曲目加一行 `src`：

```js
{
  title: '我的歌',
  artist: '涂玮轩',
  album: '汽水星球',
  tags: ['夏日', '清新'],                     // 精选页上的标签
  cover: ['#d7ff3e', '#22d3ee', '#0ea5e9'],   // 三个主色
  pattern: 'blob',                            // sun / blob / grid / wave / ring
  bpm: 124, key: 3, duration: 78,
  tone: { wave: 'square', cut: 4200, bright: 1.4 },   // 合成音色（有 src 时用不到）
  src: 'audio/我的歌.mp3',                     // ← 加了这行就播真实音频
  likes: '999+', comments: '10',
  chords: [[0, 3, 7], [5, 8, 12], [-2, 2, 5], [-4, 0, 3]],
  lyrics: [
    { t: 0,  text: '第一句歌词' },
    { t: 8,  text: '第二句歌词' }
  ],
  commentList: [
    { user: '小汽水', text: '好好听', likes: '12', time: '刚刚' }
  ]
}
```

> `lyrics` 里的 `t` 是这句歌词开始出现的秒数。

## 目录结构

```
soda-music/
├── index.html        页面结构（三个视图 + 播放条 + 抽屉 + 评论面板）
├── css/style.css     全部样式
├── js/data.js        曲库数据（改这里换歌）
├── js/audio.js       音频引擎（真实音频 / 合成音源 / 混响）
├── js/app.js         交互逻辑（视图、切歌、歌词、频谱、评论、记忆）
├── audio/            放你自己的 mp3（可选）
└── README.md
```

## 小提示

- 浏览器不允许网页一打开就自动播放，所以有个**首屏引导页**，点「进入」才会响；
- 手机上直接上下滑切歌，右侧操作栏和播放条都会自动适配；
- 所有数据都存在浏览器本地，换个浏览器就是全新的。
