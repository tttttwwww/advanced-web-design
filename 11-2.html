CSS 3D ANIMATION

立体世界：CSS 3D 动画

不用 JavaScript，只靠 perspective、transform-style: preserve-3d 和 rotateX / rotateY / translateZ，就能在浏览器里搭出会旋转的立方体、环形轮播和翻转卡片。下面每个例子都是真实可交互的 3D 场景。

五、核心属性速查 写 3D 动画记住这六个就够了

perspective

写在父容器上，设置观察者的视距；数值越小立体感越强。

.tu_stage {
  perspective: 900px;
}

transform-style

必须是 preserve-3d，子元素才会在真正的 3D 空间里摆放。

.tu_cube {
  transform-style: preserve-3d;
}

rotateX / rotateY / rotateZ

绕三条轴旋转，度数为正顺时针，可组合使用。

.tu_cube {
  transform: rotateY(45deg) rotateX(-18deg);
}

translateZ

沿 Z 轴前后移动，正值朝向观察者，用来撑开立体结构。

.tu_face-front {
  transform: translateZ(80px);
}

backface-visibility

元素背面朝向观察者时是否可见，翻转卡片的关键。

.tu_flip-face {
  backface-visibility: hidden;
}

@keyframes + transition

连续旋转用 animation，交互式翻转用 transition。

@keyframes tu_ring-spin {
  to { transform: rotateY(360deg); }
}
