Lesson 17-6 · Promise & async

包饺子的异步流程

先买原料，原料到手后同时和面、和馅（Promise.all），再依次擀皮、包饺子、煮饺子——每一步都是一个 Promise，整条流程用 async / await 串起来。

开始动手 每一步都真的在等

还没开始。点「开始包饺子」，先出门买原料。

流程 ① 买原料 → ② 同时和面 / 和馅 → ③ 擀皮 → ④ 包 → ⑤ 煮

1 买原料 等待

面粉、猪肉、白菜、调料 —— 大约 1.2 秒

② 原料到手后，这两件事同时进行：await Promise.all([和面, 和馅])

2 和面 等待

面粉加水揉成团 —— 大约 2 秒

3 和馅 等待

猪肉白菜剁碎调味 —— 大约 1.6 秒

4 擀皮 等待

面醒好了，擀成圆皮 —— 大约 1.8 秒

5 包饺子 等待

一张皮一勺馅，捏紧边 —— 大约 2.6 秒

6 煮饺子 等待

水开下锅，点三次凉水 —— 大约 2.2 秒

饺子煮好了

总用时 — 秒

如果全部串行需要 — 秒
同时和面 + 和馅省下 — 秒
并行的那一步取最长 — 秒

和面（2 秒）与和馅（1.6 秒）同时开始，总时间只算较长的那一个，所以比一步一步做要快。

    对应的代码

    async function cookDumplings() {
  await buyIngredients();                            // 先买原料
  await Promise.all([kneadDough(), mixFilling()]);   // 同时和面、和馅
  await rollWrappers();                              // 擀皮
  await wrapDumplings();                             // 包饺子
  await boilDumplings();                             // 煮饺子
  console.log('开吃！');
}

// 每个步骤都是一个「会晚点完成」的 Promise
function kneadDough() {
  return new Promise(function (resolve) {
    setTimeout(resolve, 2000);   // 和面要 2 秒
  });
}
    • await 会暂停 cookDumplings 这个函数，但不会卡住整个页面：等待期间按钮、滚动、动画都还能用。
    • Promise.all 里两个 Promise 同时启动，全部完成才算完成，耗时取最长的那一个。
    • 页面上的「重来」会作废正在跑的那一轮（用一个自增的令牌判断），已经排进队列的定时器不会乱改界面。
